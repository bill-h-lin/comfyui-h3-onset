The graphs are not identical to one another

A single “here is the workflow” file would be a false statement about this film. The shots differ in which references they bind, and that changes the node count (15 to 19).

⭐ The two-reference shots are the interesting ones. MiniMaxH3ReferenceToVideo takes a list of reference images (ref_images.ref_image_0, ref_image_1) and the prompt addresses them positionally as <Picture 1> / <Picture 2>. That is how both characters hold their identity in the same frame.
⭐ H3ZeroAudioPrefix sits in 10 of these graphs, between LoadAudio and the H3 node. It is the node in this repo doing the job it was written for.

What is not here, and why

The bound reference files themselves (lh_master_crop.png, lh_appr_full_crop.png, c5_calm_voice.wav, c5_noa_voice.wav) are not redistributed. The two images are crops of frames from text-only H3 renders made on this box. No photograph of any real person exists anywhere in the chain. Load a graph, point LoadImage/LoadAudio at your own reference, change the prompt.
